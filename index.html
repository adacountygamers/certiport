Domain 1Java fundamentals

1.1main() and running a program

public static void main(String[] args)   // the one entry point the JVM looks for
  • public: the JVM calls it from outside. static: no object exists yet when the program starts. void: returns nothing. String[] args: command-line arguments.
  • Also legal: String args[], String... args, static public, any parameter name (String[] x). Leaving out static compiles, but the launcher refuses to run it.
  • javac Grades.java compiles to bytecode Grades.class. java Grades runs it (no extension).
  • java Grades 90 85 gives args = {"90", "85"}, args.length == 2. They're Strings: args[0] + args[1] is "9085". Use Integer.parseInt(args[0]) for math.
  • No arguments: args.length == 0 (not null), and args[0] throws ArrayIndexOutOfBoundsException.

1.2Console input and output, comments

  • print = no newline. println = newline after. printf / String.format = formatted, no newline unless %n or \n.
  • %d int/long · %f double (6 decimals by default) · %.2f 2 decimals, rounded · %s String · %c char · %b boolean · %n newline · %,d 1,234 · %5d right-aligned in 5 · %-5s left-aligned · %05d zero-padded.
  • printf("%d", 3.5) compiles but throws IllegalFormatConversionException at runtime.
  • Escapes: \n newline · \t tab · \" quote · \' apostrophe · \\ backslash.
import java.util.Scanner;                 // java.lang (String, Math, System, Integer) is automatic
Scanner in = new Scanner(System.in);
int age = in.nextInt();      // also nextDouble(), nextBoolean(), next() = one word
in.nextLine();               // eat the leftover newline!
String name = in.nextLine(); // whole line, spaces included
in.close();
TrapnextInt() then nextLine() returns "": the Enter key's newline is still in the buffer. Typing abc for nextInt() throws InputMismatchException.
  • Comments: // line, /* block */, /** Javadoc */ with tags @param, @return, @throws, @author. The javadoc tool turns Javadoc into HTML docs. The compiler ignores all comments.

1.3Variable scope

  • A variable exists only inside the { } block where it's declared, from the declaration down.
  • A for (int i = 0; ...) counter is gone after the loop. Using i afterward is a compile error.
  • Local variables get no default value: reading one before assigning it is a compile error. Fields (instance/static) default to 0, 0.0, false, '\u0000' or null.
  • You can't redeclare a local inside a nested block where it's still in scope (compile error). A local or parameter can shadow a field; use this.name to reach the field.
  • Static field: one copy for the class. Instance field: one per object. Local: one per method call.

  • Compile errors: int n = 9.99; · float f = 1.5; (1.5 is a double) · long big = 3000000000; · int x = true; · short s = 1; s = s + 1; (s + 1 is int). s += 1; is fine.

2.2Strings

String s = "Java Exam";   // indexes: J=0 a=1 v=2 a=3 ' '=4 E=5 x=6 a=7 m=8
s.length()          // 9
s.charAt(5)         // 'E'          charAt(9) -> StringIndexOutOfBoundsException
s.substring(5)      // "Exam"       from 5 to the end
s.substring(0, 4)   // "Java"       end index is EXCLUDED; length = end - begin
s.indexOf("a")      // 1            first match; -1 if not found
s.lastIndexOf('a')  // 7
s.toUpperCase()     // "JAVA EXAM"  returns a NEW string; s is unchanged
s.replace('a', 'o') // "Jovo Exom"  replaces every match
s.contains("Ex")    // true         also startsWith, endsWith, isEmpty, trim, split
"b".compareTo("a")  // positive     negative = comes first, 0 = equal
  • Immutable. s.trim(); on its own line does nothing. You need s = s.trim();.
  • Compare text with s.equals(t) or s.equalsIgnoreCase(t). == compares references: "hi" == "hi" is true (pooled literals), new String("hi") == "hi" is false.
  • Concatenation goes left to right: 1 + 2 + "3" is "33"; "1" + 2 + 3 is "123"; "1" + (2 + 3) is "15"; 'A' + 1 + "" is "66"; "" + 'A' + 1 is "A1".
  • null: "x" + null is "xnull", but calling a method on a null String throws NullPointerException. "" is an empty string, not null.
  • StringBuilder is mutable: append, insert(i, x), reverse(), deleteCharAt, toString() change the same object.

2.3Arrays and ArrayList

int[] a = new int[5];          // five 0s. Defaults: 0, 0.0, false, '\u0000', null
int[] b = {4, 8, 15};          // b.length == 3 (a field: no parentheses)
int c[] = new int[]{1, 2};     // also legal.  new int[2]{1,2} is a compile error
b[b.length]                    // ArrayIndexOutOfBoundsException (last index is length - 1)
int[][] g = new int[3][4];     // g.length == 3 rows, g[0].length == 4 columns, g[row][col]
for (int v : b) { v = 0; }     // for-each gets a copy: the array is NOT changed
System.out.println(b);         // prints something like [I@6d06d69c. Use Arrays.toString(b)
import java.util.ArrayList;
ArrayList<String> list = new ArrayList<>();  // ArrayList<int> is a compile error: use Integer
list.add("a");        // [a]
list.add("c");        // [a, c]
list.add(1, "b");     // [a, b, c]   inserts and shifts right
list.set(0, "z");     // [z, b, c]   replaces, returns old value
list.remove(0);       // [b, c]      by index, returns removed element
list.remove("c");     // [b]         by value, returns true/false
list.get(0); list.size(); list.contains("b"); list.indexOf("b"); list.isEmpty(); list.clear();
TrapOn ArrayList<Integer>, nums.remove(1) removes index 1. To remove the value 1 use nums.remove(Integer.valueOf(1)). Removing while looping forward by index skips the next element; removing inside a for-each throws ConcurrentModificationException. A bad get index throws IndexOutOfBoundsException.

2.4Parsing, casting and conversion

  • String to number: Integer.parseInt("42") → int, Double.parseDouble("4.5") → double, Boolean.parseBoolean("true"), Integer.valueOf("42") → Integer object.
  • Integer.parseInt("4.5"), ("12a"), (" 7"), ("") all throw NumberFormatException (runtime).
  • Number to String: String.valueOf(42), Integer.toString(42), "" + 42.
  • Wrappers: Byte Short Integer Long Float Double Character Boolean. Autoboxing: Integer x = 5; Unboxing: int y = x; Integer.MAX_VALUE, Integer.MIN_VALUE.
  • Rounding: (int) 2.7 → 2 (truncate). Math.round(2.5) → 3, Math.round(-2.5) → -2, Math.round(2.49) → 2. Math.round(double) returns a long.
  • (double) 7 / 2 → 3.5 (cast happens first). (double)(7 / 2) → 3.0 (int division happens first).

2.5Arithmetic and operators

  • Precedence, high to low: () → x++ x-- → ++x --x ! -x (cast) → * / % → + - → < > <= >= → == != → && → || → ?: → = += -=. Same level goes left to right.
  • int ÷ int = int: 7 / 2 → 3, -7 / 2 → -3, 1 / 3 * 3 → 0. Any double makes it double: 7 / 2.0 → 3.5.
  • % remainder: 17 % 5 → 2, 3 % 8 → 3, -7 % 3 → -1 (sign follows the left side), 5.5 % 2 → 1.5. Even test: n % 2 == 0.
  • x++ uses the old value, then adds. ++x adds first. int x = 5; int y = x++ + ++x; → y = 5 + 7 = 12, x = 7.
  • Compound ops cast for you: int n = 10; n += 2.9; compiles (n = 12), but n = n + 2.9; doesn't. n *= 2 + 3 means n = n * (2 + 3).
  • Math: Math.pow(2, 3) → 8.0 (double, so int p = Math.pow(2,3); won't compile) · Math.sqrt(25) → 5.0 · Math.abs(-4) → 4 · Math.max/min · Math.ceil(2.1) → 3.0 · Math.floor(-2.1) → -3.0 · Math.random() → 0.0 up to but not including 1.0.
  • Random int from 1 to 6: (int)(Math.random() * 6) + 1. From 5 to 15: (int)(Math.random() * 11) + 5 (count = max − min + 1).
  • 5 / 0 and 5 % 0 throw ArithmeticException. 5.0 / 0 is Infinity; 0.0 / 0 is NaN. No exception for doubles.

Domain 3Flow control

3.1Branching

  • In an if / else if / else chain only the first true branch runs. Order matters: if (score >= 60) before if (score >= 90) means 95 gets the first branch.
  • No braces: the if controls exactly one statement. Indentation means nothing to Java. An else pairs with the nearest unmatched if.
  • if (x > 5); ends the if with an empty statement, so the block below always runs.
  • if (x = 5) with an int is a compile error. if (done = true) with a boolean compiles, assigns, and is always true.
  • && and || short-circuit: s != null && s.length() > 0 never calls length() on null. & and | always evaluate both sides. ! binds tightest, then &&, then ||: a || b && c means a || (b && c).
  • Ternary: String r = (n % 2 == 0) ? "even" : "odd";
switch (day) {              // int, char, byte, short, String, enum (and their wrappers)
    case 1:                 // NOT long, float, double, boolean
    case 7:  System.out.print("weekend "); break;
    case 2:  System.out.print("mon ");     // no break: falls through into case 3
    case 3:  System.out.print("tue ");     break;
    default: System.out.print("other ");   // runs when no case matches
}                           // day = 2 prints "mon tue "
  • Case labels must be constants and unique. String cases are case-sensitive. default can go anywhere, and execution falls through it too if there's no break.

3.2Loops

  • while (cond) checks first, so it may run 0 times. do { } while (cond); always runs at least once (note the semicolon).
  • Count iterations: for (int i = a; i < b; i++) runs b − a times; with <= it's b − a + 1. for (int i = 0; i < 10; i += 3) runs for 0, 3, 6, 9: four times. for (int i = 1; i < 50; i *= 2): 1, 2, 4, 8, 16, 32 (six times).
  • break leaves the innermost loop or switch. continue jumps to the next iteration (in a for, the update still runs; in a while, a continue before i++ makes an infinite loop).
  • Nested loops: total inner runs = outer count × inner count (when independent). With j < i it's a triangle: 0 + 1 + 2 + ...
  • A for-each loop has no index and can't replace elements. for (String s : list) works on arrays and ArrayLists.
  • Infinite: for (;;), while (true) without a break, or a counter that moves the wrong way.

Domain 4Object-oriented programming

4.1Classes and constructors

public class Account {                    // must live in Account.java (one public class per file)
    private String owner;                 // fields = state
    private double balance;
    private static int count = 0;         // shared by ALL Account objects

    public Account(String owner) {        // constructor: class name, NO return type
        this(owner, 0.0);                 // this(...) must be the first statement
    }
    public Account(String owner, double balance) {   // overloaded constructor
        this.owner = owner;               // this.owner = field, owner = parameter
        this.balance = balance;
        count++;
    }
    public double getBalance() { return balance; }   // getter
    public void setBalance(double b) { balance = b; } // setter
}
  • public void Account() is a method named Account, not a constructor.
  • Write no constructor and Java gives you a free no-arg one. Write any constructor and that free one disappears: new Account() then won't compile.
  • owner = owner; (without this.) assigns the parameter to itself. The field stays null. This is a logic error, not a compile error.
  • Inheritance: class Savings extends Account. One parent only. Constructors are not inherited. Private members exist but aren't accessible in the child.
  • super(...) must be the first line of a child constructor. If you leave it out, Java inserts super(), which fails to compile when the parent has no no-arg constructor.
  • Overriding: same name and same parameters in the child (use @Override). Account a = new Savings("x"); then a.method() runs Savings' version. You can't make an overriding method less visible. super.method() calls the parent's version.

  • Encapsulation: private fields plus public getters and setters (getName(), setName(..), isActive() for booleans). Setters can validate.
  • static field: one copy shared by every object; access it as ClassName.field. Classic use: counting objects created.
  • final variable: assign once, then reassigning is a compile error. static final = class constant, named UPPER_CASE. A final method can't be overridden; a final class can't be extended.

4.3Methods

  • Shape: modifiers returnType name(parameters) { }. A void method can't return a value (a bare return; is fine). A non-void method must return a value on every path, or it won't compile.
  • Overloading: same name, different parameter list (number, type or order). A different return type alone is not overloading (compile error). Java picks the closest match: f(5) prefers f(int) over f(double); if there's only f(double), the int widens.
  • A static method has no this. It can't touch instance fields or call instance methods directly (compile error: "non-static ... cannot be referenced from a static context"). It must create an object first.
  • Java is pass-by-value. A primitive argument is copied: the caller's variable never changes. An object argument copies the reference: changing the object's fields is visible to the caller, but pointing the parameter at a new object is not.

4.4Objects and references

  • Dog d = new Dog(); → new creates the object, runs the constructor, returns a reference. Dog e = d; copies the reference: both names point to one object.
  • == on objects: same object? .equals(): same content (when the class overrides it, like String).
  • null = points at nothing. Calling a method on it throws NullPointerException. Object fields default to null.
  • Garbage collection: an object becomes eligible once nothing references it (variable set to null, reassigned, or out of scope). The JVM decides when. System.gc() only suggests it; you can't force it.
  • System.out.println(obj) calls obj.toString(). Without an override it prints something like Dog@1b6d3586.

5.2Exception handling

try {
    int r = 10 / d;                 // if this throws, the rest of try is skipped
    System.out.println("done");
} catch (ArithmeticException e) {   // most specific first
    System.out.println(e.getMessage());   // "/ by zero"
} catch (Exception e) {             // broadest last; reversing the order = compile error
    System.out.println(e);          // "java.lang.ArithmeticException: / by zero"
} finally {
    System.out.println("always");   // runs whether or not anything was thrown, even after return
}
System.out.println("after");        // runs if the exception was caught
  • Hierarchy: Throwable → Error (OutOfMemoryError, StackOverflowError: don't catch) and Exception → RuntimeException (unchecked) plus the checked ones.
  • Checked (IOException, FileNotFoundException, Exception itself): you must catch it or declare throws IOException in the method header, or it won't compile. Unchecked (RuntimeException and its subclasses): optional.
  • throw new IllegalArgumentException("Age can't be negative"); throws one. throws (with an s) goes in the method signature.
  • Multi-catch: catch (NumberFormatException | ArithmeticException e). A try needs at least one catch or a finally.
  • If no catch matches, finally still runs, then the exception keeps going up and the program crashes with a stack trace.
  • e.getMessage() = message only. e.toString() / println(e) = class name + message. e.printStackTrace() = full trace.

  • About 35 to 45 items in 50 minutes; 700 out of 1000 (scaled) passes. Budget a bit over a minute per question and mark slow ones for review.
